# Ассемблер и интерпретатор для УВМ (Вариант №23)

## Язык ассемблера (JSON)

Программа представляет собой JSON-массив объектов. Каждый объект описывает одну команду.
Поддерживаются следующие команды:

- `load_const` (операнд: число) — загрузка константы в аккумулятор (A=11).
- `read_mem` — чтение значения из памяти по адресу в аккумуляторе (A=8).
- `write_mem` (операнд: адрес) — запись значения аккумулятора в память по адресу (A=10).
- `sgn` — унарная операция смены знака (A=1).

**Пример программы (`test_program.json`):**

````json
[
    {"command": "load_const", "operand": 344},
    {"command": "read_mem"},
    {"command": "write_mem", "operand": 630},
    {"command": "sgn"}
]

## Тестирование (Демонстрация работы)

Для демонстрации работоспособности программы используются различные сценарии запуска.

### 1. Успешный запуск в режиме тестирования
Показывает, что ассемблер корректно переводит JSON-команды во внутреннее представление (поля A и B) в точном соответствии со спецификацией УВМ.

**Вводим:**
```bash
python src/main.py -s test_program.json -o output.bin -t

Должно вывести:
Тест (A=11, B=344):
Тест (A=8):
Тест (A=10, B=630):
Тест (A=1):

### 2. Показывает работу программы без флага тестирования
**Вводим:**
```bash
python src/main.py -s test_program.json -o output.bin

Должно вывести:
Программа успешно прочитана. Команд: 4.
Выходной файл output.bin будет создан на Этапе 2.

### 3. Показывает защиту от неверного ввода пути к исходному файлу.
**Вводим:**
```bash
python src/main.py -s nonexistent.json -o output.bin -t

Должно вывести:
Ошибка: Файл программы не найден: nonexistent.json

### 4. Показывает защиту от синтаксических ошибок в файле программы.
(Для проверки создайте файл bad.json с текстом: {"command": "load_const", })

**Вводим:**
```bash
python src/main.py -s bad.json -o output.bin -t

Должно вывести:
Ошибка: файл программы содержит некорректный JSON.

### 4. Показывает, что ассемблер не пропускает команды, которых нет в спецификации.
(Для проверки создайте файл bad_cmd.json с текстом: [{"command": "invalid_cmd"}])

**Вводим:**
```bash
python src/main.py -s bad_cmd.json -o output.bin -t

Должно вывести:
Ошибка: Неизвестная команда: invalid_cmd
````
